║  OPTION B: Enable Google Cloud Vision (3 Steps)                           ║
╚═══════════════════════════════════════════════════════════════════════════╝

    Step 1: Get API Credentials
    ────────────────────────────────────────────────────────────────────────
    1. Visit: https://console.cloud.google.com/
    2. Create project → Enable "Cloud Vision API"
    3. Create Service Account → Download JSON key
    4. Save as: google-vision-credentials.json

    Step 2: Configure Environment
    ────────────────────────────────────────────────────────────────────────
    Windows PowerShell:
    
      $env:GOOGLE_APPLICATION_CREDENTIALS="path\to\google-vision-credentials.json"
      $env:OCR_ENGINE="google_vision"

    OR use the quick setup script:
    
      setup_google_vision.bat "path\to\google-vision-credentials.json"

    Step 3: Run Application
    ────────────────────────────────────────────────────────────────────────
      python app.py

┌─────────────────────────────────────────────────────────────────────────────┐
│ ⚙️  CONFIGURATION                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

    Environment Variables:
    ──────────────────────────────────────────────────────────────────────────
    OCR_ENGINE                        Choose engine
      ├─ "trocr"                      Use TrOCR (default)
      ├─ "google_vision"              Use Google Vision
      └─ "auto"                       Auto-detect (prefers Google)

    GOOGLE_APPLICATION_CREDENTIALS    Path to JSON key file
      └─ "path/to/credentials.json"

    Programmatic Usage:
    ──────────────────────────────────────────────────────────────────────────
    from backend.ocr_processor import extract_text_from_image

    # Use configured engine
    text = extract_text_from_image('image.jpg')

    # Force specific engine
    text = extract_text_from_image('image.jpg', engine='trocr')
    text = extract_text_from_image('image.jpg', engine='google_vision')

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🆘 TROUBLESHOOTING                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

    Problem: "Google Cloud Vision API not initialized"
    ────────────────────────────────────────────────────────────────────────
    Solution:
      ✅ Set GOOGLE_APPLICATION_CREDENTIALS environment variable
      ✅ Verify JSON key file exists and path is correct
      ✅ Restart terminal/IDE after setting variables

    Problem: "Permission denied" or "API not enabled"
    ────────────────────────────────────────────────────────────────────────
    Solution:
      ✅ Enable Cloud Vision API in Google Cloud Console
      ✅ Check service account has correct roles
      ✅ Verify billing is enabled (even for free tier)

    Problem: Still using TrOCR when I want Google Vision
    ────────────────────────────────────────────────────────────────────────
    Solution:
      ✅ Check OCR_ENGINE environment variable is set to "google_vision"
      ✅ Restart application after setting environment variables
      ✅ Look for "Using OCR engine: google_vision" in console output
