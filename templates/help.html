Getting Started

1. Create an Account

Sign up with your email address and create a password. You'll receive a confirmation and can start using the system immediately.

2. Login

Access your dashboard using your credentials. Students see their evaluations, while admins see all submissions.

3. Navigate the Dashboard

From the dashboard, you can:

  • View your statistics and recent evaluations
  • Upload new exams
  • Check results
  • Update your profile

Uploading Exams

Supported File Formats

  • Images: PNG, JPG, JPEG
  • Documents: PDF
  • Maximum Size: 10MB per file

Upload Steps

  1. Go to the Upload page
  2. Drag and drop your file or click to browse
  3. Fill in the exam details:
    • Subject (e.g., Computer Science)
    • Exam Type (Test, Quiz, Assignment, etc.)
    • Total Marks
    • Mode (Offline for scanned, Online for typed)
  4. Review the extracted text (for scanned papers)
  5. Provide model answers
  6. Click "Upload & Evaluate"

Tip: For best OCR results, use high-quality scans (300 DPI or higher) with good lighting and no shadows.

Providing Model Answers

Format 1: JSON (Recommended)

{
  "questions": [
    {
      "question_number": 1,
      "question": "What is OOP?",
      "model_answer": "Object-Oriented Programming...",
      "max_marks": 10
    },
    {
      "question_number": 2,
      "question": "Explain inheritance.",
      "model_answer": "Inheritance is...",
      "max_marks": 10
    }
  ]
}

Format 2: Structured Text

Q1: What is OOP?
A1: Object-Oriented Programming is a paradigm...

Q2: Explain inheritance.
A2: Inheritance is a mechanism...

Important: Model answers must match the question numbers in the student's exam paper.

Understanding Results

Score Calculation

The system uses Natural Language Processing (NLP) to evaluate answers:

  • Text Preprocessing: Removes punctuation, stop words, and lemmatizes text
  • Keyword Extraction: Identifies important terms using TF-IDF
  • Similarity Score: Calculates cosine similarity between student and model answers
  • Final Score: Similarity percentage × Maximum marks

Score Ranges

Percentage Grade Meaning
90-100% A+/A Excellent understanding
80-89% B+/B Very good understanding
70-79% C+/C Good understanding
60-69% D+/D Satisfactory
Below 60% F Needs improvement

Results Include

  • Overall Score: Total marks obtained and percentage
  • Question-wise Breakdown: Individual scores for each question
  • Keyword Analysis: Matched and missed keywords
  • Feedback: Strengths, areas to improve, and suggestions
  • Visual Charts: Score distribution and performance graphs

Exam Format Guidelines

✅ Correct Format

Student answers must be clearly numbered:

Q1: Answer to question one...
Q2: Answer to question two...
Q3: Answer to question three...

Or:

1. Answer to question one...
2. Answer to question two...
3. Answer to question three...

❌ Incorrect Format

  • No question numbers or markers
  • Inconsistent formatting
  • Mixed numbering styles
  • Answers running together without separation

Best Practice: Instruct students to clearly mark each question (Q1:, Q2:, etc.) before their answers for accurate evaluation.

Troubleshooting

OCR Not Working

  • Ensure handwriting is legible
  • Use high-quality scans (300+ DPI)
  • Avoid shadows and glare
  • Keep paper flat and aligned

Low Scores Despite Good Answers

  • Check if model answers are comprehensive
  • Verify student used similar terminology
  • Review extracted text for OCR errors
  • Ensure question numbering matches

All Questions Getting Same Score

  • Verify student answers are properly numbered (Q1:, Q2:, etc.)
  • Check that answers are separated, not running together
  • Review the extracted text to ensure correct parsing

Upload Fails

  • Check file size (max 10MB)
  • Verify file format (PNG, JPG, JPEG, PDF)
  • Try a different browser
  • Clear browser cache

Evaluation Takes Too Long

  • Large images may take longer to process
  • Multiple questions require more computation time
  • Wait up to 30 seconds for complex evaluations
  • Check internet connection

Frequently Asked Questions

Q: How accurate is the evaluation?

A: The NLP-based evaluation provides similarity scores based on keyword matching and content analysis. While highly accurate for factual content, subjective answers may require manual review.

Q: Can I edit evaluation results?

A: Admins can edit feedback. However, scores are automatically calculated and cannot be manually changed to maintain consistency.

Q: Does it work with handwriting?

A: Yes! Our OCR engine can process handwritten text. For best results, ensure clear, legible handwriting.

Q: Can I evaluate multiple exams at once?

A: Currently, exams are evaluated one at a time. Batch processing may be added in future updates.

Q: How long are results stored?

A: All evaluation results are stored indefinitely in your account and can be accessed anytime.

Q: Can I download my results?

A: Yes! Click the "Download PDF" button on any result page to get a professional report.

Q: Is my data secure?

A: Absolutely. We use industry-standard encryption, secure sessions, and role-based access control to protect your data.
